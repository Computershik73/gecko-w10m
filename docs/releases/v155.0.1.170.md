Gecko 155 (Firefox 155.0.1) for Windows 10 Mobile, ARM, build 155.0.1.170.

**Requirements:** Windows 10 Mobile 1703 (15063) or newer, interop unlock (the package declares restricted capabilities: `codeGeneration` for the JIT, file-system access for the profile), the signing certificate `Gecko.cer` trusted on the phone. See `INSTALL.txt`. It installs over 155.0.1.140 and keeps the profile.

**Changes since 155.0.1.140**

Microphone and calls
- Sites can ask for the microphone: the permission prompt appears (before, the request went nowhere and the site waited forever), the phone's own microphone consent is asked for the app the first time, and answering it no longer closes the browser.
- The microphone works more than once per run, and recording works: microphone test sites record and play back.
- The permission prompt fits the screen, sits above the bottom bar, and its microphone list opens upwards or scrolls.
- WebRTC calls: no "sharing" indicator window, call audio on the loudspeaker.

Sites
- WebAssembly works again.
- WhatsApp Web opens (it crashed the browser) and gets its desktop version; so does Discord ("this browser is not supported" is gone).
- Text on pages made for computers (no mobile layout) is enlarged to a readable size, as Firefox for Android does.
- Downloads go to Downloads\Gecko (or a folder chosen in the settings), "Save as" works, and so do the system file pickers, uploads and opening downloaded files.
- Copy and paste work with the phone's clipboard, both ways.
- Audio keeps playing with the screen locked or the browser in the background.
- Windows a page opens become tabs, sign-in popups included (from 140).

Touch, buttons and windows
- The Back button closes the keyboard, an open menu or dialog, fullscreen or the address bar being edited, goes back in the tab's history, closes a tab a page opened back to its opener, and otherwise sends the browser to the background.
- Dialogs ("open this link?", slow-script warnings, prompts) can be answered and closed; popups and panels close on a tap outside or the Back button.
- Taps in landscape land where the finger is; quick taps (captchas, small buttons) register; a feed that scrolls while it loads no longer jumps.
- Downloads, history and bookmarks (the Library) open in tabs.
- Panels and prompts no longer run off the right edge of the screen.
- The interface follows the screen's density, so it is the same size on every phone; the toolbar follows the browser theme.

Stability
- Fixed hangs at start (the phone's clipboard) and the endless logo after failed starts: Firefox's automatic Safe Mode is off, and after repeated failed starts the browser says so on the splash for one launch, then starts normally again.
- Fixed crashes on pages that ask for cross-origin isolation and when a dialog is closed by tapping outside it.
- A microphone stream that fails mid-way no longer freezes the page's audio.

Logs (Settings > About > Verbose logs for debugging, as before)
- The log now says what the network did for slow or failed pages, which scripts or stylesheets failed to load, and how memory is laid out when it runs short.
- Nothing from private windows is logged, and addresses in the log lose user names, passwords, query strings and fragments.

**Known issues**
- This is a 32-bit browser with 2 GB of address space. Heavy web apps (Discord after login) together with extensions that keep large caches (uBlock Origin) can run out of it; the page then keeps loading. Disabling the extension, or some of its filter lists, helps.
- No camera: sites that ask for video get "not found".
- VP9 and AV1 are decoded in software; YouTube is steered to H.264, which is decoded on the GPU.
- Phones with 1 GB of RAM and a Direct3D 9-class GPU (Lumia 550/650/950) run it, but slowly; WebGL on them has no GPU acceleration.

Tested on HP Elite X3 (Snapdragon 820, 4 GB RAM) and Lumia 650 (Snapdragon 212, 1 GB RAM).
